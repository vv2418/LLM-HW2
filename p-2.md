### Python server code (server.py):
```python
from flask import Flask
import socket
import os
from datetime import datetime

app = Flask(__name__)

@app.route('/')
def home():
    greeting = "Hello! Welcome to the minimal web server."
    hostname = socket.gethostname()
    timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    
    response = f"""
    <html>
        <head><title>Minimal Server</title></head>
        <body>
            <h1>{greeting}</h1>
            <p><strong>Hostname:</strong> {hostname}</p>
            <p><strong>Timestamp:</strong> {timestamp}</p>
        </body>
    </html>
    """
    return response

if __name__ == '__main__':
    port = int(os.environ.get('PORT', 5000))
    app.run(host='0.0.0.0', port=port, debug=True)

```

### Dockerfile:
```dockerfile
# Use Python 3.11 slim base image
FROM python:3.11-slim

# Set environment variable for port
ENV PORT=8000

# Create a non-root user
RUN useradd -m -u 1000 appuser

# Set working directory
WORKDIR /app

# Copy requirements first for better caching
COPY requirements.txt .

# Install dependencies
RUN pip install --no-cache-dir -r requirements.txt

# Copy application code
COPY app/ ./app/

# Change ownership of the app directory to non-root user
RUN chown -R appuser:appuser /app

# Switch to non-root user
USER appuser

# Expose the port
EXPOSE 8000

# Run the server
CMD ["python", "app/server.py"]

```

### Kubernetes manifests:

#### deploy.yaml

```yml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: web
  labels:
    app: web
spec:
  replicas: 2
  selector:
    matchLabels:
      app: web
  template:
    metadata:
      labels:
        app: web
    spec:
      containers:
      - name: k8s-warmup
        image: myuser/k8s-warmup:v0.1
        imagePullPolicy: IfNotPresent
        env:
        - name: PORT
          value: "8000"
        ports:
        - containerPort: 8000
          name: http
        readinessProbe:
          httpGet:
            path: /
            port: 8000
          initialDelaySeconds: 5
          periodSeconds: 10
          timeoutSeconds: 2
          successThreshold: 1
          failureThreshold: 3

```

#### service.yaml
```yml
apiVersion: v1
kind: Service
metadata:
  name: web
  labels:
    app: web
spec:
  type: ClusterIP
  selector:
    app: web
  ports:
  - port: 80
    targetPort: 8000
    protocol: TCP
    name: http

```

### g)Write and apply a Deployment manifest (3 pts)
**Explanation:**
- **Deployment**: Manages a replicated set of Pods
- **replicas: 2**: Runs 2 copies of the application for high availability
- **selector**: Identifies which Pods belong to this Deployment
- **image**: Specifies the container image to use
- **imagePullPolicy: IfNotPresent**: Uses local image if available (for kind clusters)
- **env**: Sets environment variables in the container
- **containerPort**: Declares which port the container listens on
- **readinessProbe**: Health check that determines when a Pod is ready to receive traffic
<img width="1329" height="684" alt="g1" src="https://github.com/user-attachments/assets/c7c6bd03-4c64-4078-bba1-2e49dc1585a4" />

### h)Create and apply a Service manifest (2 pts)
**Explanation:**
- **Service**: Provides a stable network endpoint for accessing Pods
- **type: ClusterIP**: Internal-only service (not accessible from outside the cluster)
- **selector**: Determines which Pods receive traffic (matches the Deployment's labels)
- **port: 80**: The port the Service listens on
- **targetPort: 8000**: The port on the Pod where traffic is forwarded
